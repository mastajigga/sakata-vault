# Les bases du Kisakata — Structure et prononciation

## Sujet
Le Kisakata est une langue bantoue parlée par le peuple Basakata le long de la rivière Lukenie en République Démocratique du Congo (RDC).

## Caractéristiques linguistiques

### Langue tonale
Le Kisakata est une langue tonale. Les tons (haut et bas) changent le sens des mots.

### Structure SVO
La structure de phrase suit le modèle Sujet-Verbe-Objet (SVO), comme la plupart des langues bantoues.

### Classes nominales
Les classes nominales utilisent des préfixes. Exemples :
- mu-/ba- pour les humains (singulier/pluriel)
- Autres classes nominales existent pour les objets, animaux, concepts abstraits, etc.

### Alphabet
L'alphabet utilise des caractères latins avec des accents pour indiquer les tons (accent aigu pour ton haut, accent grave pour ton bas).

## Contexte culturel
- Peuple : Basakata
- Localisation : le long de la rivière Lukenie, RDC
- Famille linguistique : Bantoue
